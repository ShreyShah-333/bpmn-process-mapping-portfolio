# BPMN Process Mapping Portfolio

Business Analyst portfolio showcasing BPMN 2.0 process mapping skills across real-world operational workflows. Each process below documents the as-is workflow, swimlanes (roles), key decision gateways, exception handling, and improvement opportunities, paired with a diagram.

## Skills Demonstrated
- BPMN 2.0 notation: tasks, gateways, events, and swimlanes/pools
- Process discovery, documentation, and stakeholder mapping
- Gap analysis and process improvement recommendations
- Translating operational workflows into clear, auditable diagrams

## Processes Mapped
1. [Procure-to-Pay](processes/procure-to-pay.md) - requisition, approval, PO issuance, three-way match, and payment.
2. [Customer Onboarding](processes/customer-onboarding.md) - contract handoff through KYC verification to active account.
3. [Real Estate Investment Approval](processes/real-estate-investment-approval.md) - deal screening, committee approval, due diligence, and closing.

## Repository Structure
```
processes/
  procure-to-pay.md
  customer-onboarding.md
  real-estate-investment-approval.md
```

Each process file contains a Mermaid flowchart diagram (rendered natively on GitHub) organized by swimlane, plus a written breakdown of decision points, exceptions, KPIs, and improvement opportunities.
